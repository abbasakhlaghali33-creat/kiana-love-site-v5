# Kiana Love Site V5
نسخه V5 سایت شخصی و عاشقانه «۲۱».

## قابلیت‌های جدید
- اتاق مخفی با رمز
- سه بازی: کوییز، پیدا کردن شکوفه‌ها، Memory
- پیام نهایی پس از تکمیل هر سه بازی
- طراحی RTL و سازگار با موبایل
- عکس‌های نسخه قبلی حفظ شده‌اند

## رمز ورود اتاق مخفی
`21-SEA-BLOSSOM`

برای امنیت واقعی، این رمز در JavaScript قابل مشاهده است؛ بنابراین این بخش «مخفی/شخصی» است، نه امنیت واقعی. برای محافظت واقعی از عکس‌ها و محتوا باید احراز هویت سمت سرور یا سرویس خصوصی استفاده شود.

## آهنگ
فایل `our-song.mp3` را در ریشه سایت قرار دهید؛ نسخه قبلی شما همین نام را استفاده می‌کند.
